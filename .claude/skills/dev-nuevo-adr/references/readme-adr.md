Formato MADR. Una decisión por archivo, en esta carpeta.

## Nombre de archivo

`NNNN-ESTADO-titulo-con-guiones.md`. El estado va en el nombre y en la cabecera `status`, y deben coincidir.

Cada cambio de estado renombra el archivo y obliga a actualizar los enlaces y este índice.
